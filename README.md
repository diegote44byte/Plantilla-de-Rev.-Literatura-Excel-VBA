# Plantilla-de-Rev.-Literatura-Excel-VBA

Diseñé una plantilla con macros para sistematizar la revisión de literatura de una tesis de economía, con fichas de 17 campos: pregunta, datos, metodología, resultados y brecha.
Automaticé el registro, la búsqueda, la edición y la eliminación de fuentes con VBA. Incluye IDs automáticos, validación de campos obligatorios y detección de duplicados.
Estandaricé la clasificación de los estudios con listas desplegables de metodologías econométricas (DiD, variables instrumentales, RDD, VAR, etc.) y unidades de análisis.
La publiqué como proyecto de código abierto, con documentación en GitHub.
